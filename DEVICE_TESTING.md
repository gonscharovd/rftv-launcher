## 7. OTA — отрицательные и повторные сценарии

- [ ] Повторная проверка после установки сообщает, что новой версии нет.
- [ ] При отсутствии сети показывается понятная ошибка; лаунчер продолжает работать.
- [ ] Отказ пользователя в Android installer не ломает RFTV.
- [ ] Если Android запросит разрешение «Установка неизвестных приложений», оно запрашивается только для RFTV.
- [ ] Повторный запуск OTA после отказа работает корректно.
- [ ] Неверный hash/повреждённый APK не передаётся установщику (не проверять подменой реального Release; достаточно наблюдения штатных сообщений или тестовой CI-фикстуры).
- [ ] APK с другим сертификатом или package должен быть отклонён до установки.
- [ ] Настройки сохраняются после OTA и холодного перезапуска.
- [ ] В версии 0.9.0 нет повторного предложения той же версии как доступного обновления.

## Дополнение для RFTV 0.9.0 — визуальная и сетевая приёмка

Перед проверкой убедиться, что установлена версия 0.9.0 / versionCode 12.

### Визуальный язык tvOS
- [ ] Home показывает реальную фотографию на весь экран, без синего градиента вместо изображения.
- [ ] Часы — главный центральный элемент, дата читается и не обрамлена большой карточкой.
- [ ] Погода отображается компактной стеклянной плашкой; OK открывает прогноз.
- [ ] Dock — единая тёмная стеклянная капсула, нет отдельных рамок у каждой невыбранной иконки.
- [ ] Фокус увеличивает и подсвечивает только выбранную иконку; подпись появляется у выбранного приложения.
- [ ] Control Center плавает справа и заканчивается выше Dock; ни один элемент Dock не перекрыт.
- [ ] Настройки используют тёмную стеклянную поверхность, постоянную левую навигацию и правую область раздела; нет синей заливки и однотипных ярких рамок.
- [ ] Back возвращает на прежний экран, DPAD перемещает фокус без тупиков.

### Фотографии и offline
- [ ] После установки все дневные и ночные фото доступны без ожидания сетевой загрузки.

### Погода и fallback
- [ ] Home показывает температуру, условие и Челябинск.
- [ ] OK открывает прогноз; даты, минимумы и максимумы отображаются.
- [ ] Источник данных указан (Open-Meteo / MET Norway / wttr.in).
- [ ] После успешной загрузки данные остаются доступными offline из кэша.
- [ ] При недоступности первого провайдера выполняется переход на следующий; не показываются выдуманные данные.
- [ ] Заставка показывает те же кэшированные погодные данные.
