# RFTV Launcher — проверка на реальном телевизоре

## Тестовая сборка

- Приложение: RFTV Launcher
- Package ID: `com.rftv.launcher`
- Версия-кандидат: `0.4.0` (versionCode `4`)
- Формат: подписанный Release APK
- Минимальная версия Android: API 24
- Целевая версия Android: API 28
- Стабильный APK: [GitHub Releases](https://github.com/gonscharovd/rftv-launcher/releases) (после публикации v0.4.0)
- OTA: встроенный обновлятор RFTV

CI подтверждает тесты, lint, Debug metadata и отдельную проверку постоянной Release-подписи. Это не заменяет физическое тестирование на Sber SDX-50U4123B. До публикации Release и проверки артефакта не устанавливать сборки из feature-веток.

## Важная безопасность

- Не отключать штатный Salute TV / StarOS launcher.
- Не назначать RFTV приложением Home по умолчанию без отдельной проверки.
- Не использовать root, команды ADB для отключения пакетов или TV Cleaner для системных компонентов.
- Не сбрасывать данные RFTV: настройки обоев, темы и избранное должны сохраниться при OTA.
- Если Android запросит разрешение на установку неизвестных приложений, разрешить его только RFTV и только после проверки источника APK.

## A. Установка

### Способ 1 — OTA (предпочтительно, если установлена RFTV 0.3.0)

1. Открой RFTV → настройки лаунчера → раздел «О системе» / обновления.
2. Нажми «Проверить обновления GitHub».
3. Убедись, что найдена версия 0.4.0.
4. Запусти «Скачать и проверить обновление».
5. Дождись проверок SHA-256, package name, увеличения versionCode, ABI и сертификата.
6. Подтверди установку в штатном Android installer.
7. После завершения запусти RFTV и проверь сохранность настроек.

### Способ 2 — подписанный Release APK (если RFTV не установлена)

1. Открой [GitHub Releases](https://github.com/gonscharovd/rftv-launcher/releases) и скачай `app-release.apk` из стабильного v0.4.0.
2. Перенеси APK на USB-накопитель и открой его штатным файловым менеджером ТВ.
3. Проверь, что Android показывает приложение RFTV Launcher и версию 0.4.0.
4. Подтверди установку. Не выбирай RFTV домашним приложением по умолчанию на первом запуске.
5. Если установка блокируется, сообщи точный текст ошибки. Не устанавливай сторонние APK-файловые менеджеры.

Не устанавливай Debug APK на телевизор. ADB для этой приёмки не требуется.

## B. Первый запуск и интерфейс

Поставьте отметку после каждой проверки:

- [ ] APK установился без ошибки.
- [ ] RFTV виден в списке приложений телевизора.
- [ ] Приложение запускается вручную из списка приложений.
- [ ] Главный экран отображается без вылета.
- [ ] Часы и дата видны и обновляются.
- [ ] На экране появляется фоновое изображение (после загрузки; первый запуск может требовать интернет).
- [ ] Нижний Dock отображает доступные приложения.
- [ ] Стрелки пульта перемещают фокус предсказуемо.
- [ ] OK/Enter открывает выбранное приложение или элемент.
- [ ] DOWN раскрывает второй ряд Dock, UP сворачивает его.
- [ ] После установки/удаления приложения Dock и каталог обновляются без перезапуска.
- [ ] Избранное и фокус не сбрасываются после обновления другого приложения.
- [ ] Если очистить избранное намеренно, оно остаётся пустым после повторного сканирования.
- [ ] BACK закрывает панель или возвращает на главный экран.
- [ ] Дата в ручной заставке и системной заставке меняется корректно при смене суток.
- [ ] RFTV не перехватывает штатную кнопку Home без выбора пользователя.

## C. Функции

- [ ] Открывается панель погоды.
- [ ] При медленном/отсутствующем интернете экран погоды не зависает и поздний ответ не меняет уже открытый экран.
- [ ] Погода отображается при подключённом интернете.
- [ ] Открывается Control Center / настройки RFTV.
- [ ] Переключение светлой/тёмной темы работает.
- [ ] Ручной выбор обоев работает.
- [ ] Переключение карусели работает.
- [ ] Открываются системные настройки через предусмотренные ярлыки.
- [ ] При отключённом интернете приложение не падает; остаётся последнее доступное изображение или фон-заглушка.

## D. Стабильность и возврат

- [ ] Закрытие и повторный запуск RFTV работают.
- [ ] После перезагрузки телевизора штатный интерфейс остаётся доступен.
- [ ] После временной потери интернета приложение продолжает работать.
- [ ] После 30 минут работы нет заметного замедления или зависания.
- [ ] Штатный Salute TV / StarOS launcher по-прежнему запускается из списка приложений/кнопки Home.

## Как сообщать о результате

Пришлите:
1. Номер этапа и пункта, например «B, пункт 4».
2. Что ожидали увидеть и что произошло фактически.
3. Точный текст ошибки, если он есть.
4. Фотографию экрана, если проблема визуальная.

Если приложение падает, сначала сообщите, на каком действии это происходит и повторяется ли ошибка после повторного запуска. Не выполняйте очистку данных приложения до обсуждения: в настройках могут храниться выбранные обои и параметры.

## Ограничения текущего Release candidate

- Успешная CI-сборка подтверждает компиляцию и упаковку APK, но не гарантирует совместимость с конкретной модификацией StarOS.
- В текущем интерфейсе погодный город пока задан в коде; выбор города ещё не реализован.
- Доступность системной заставки DreamService зависит от прошивки StarOS и должна проверяться отдельно.
- Некоторые системные экраны настроек могут быть недоступны или переименованы производителем.
- Приложение пока не является заменой системного лаунчера и не выполняет привилегированные операции.
