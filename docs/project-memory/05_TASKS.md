## Последовательность при временной недоступности ТВ

1. Продолжать off-device этап 3: дизайн-токены, производительность отрисовки, unit tests, lint и CI.
2. Сохранять RFTV-001 физической приёмки v0.3.0 в IN PROGRESS / NOT VERIFIED; при появлении доступа пройти `DEVICE_TESTING` и устранить P0-дефекты.
3. После завершения этапа 3 перейти к этапу 4 Dock/каталога; аппаратные критерии остаются отдельным acceptance gate.

Разрешение Product Owner относится только к off-device работе и не заменяет физическую проверку.

## Правила ведения

- Перед добавлением задачи проверьте, нет ли её уже в списке и [ROADMAP](../../ROADMAP.md).
- Используйте только статусы BACKLOG, READY, IN PROGRESS, BLOCKED, REVIEW, DONE.
- Не ставьте DONE по факту написания кода: требуемые критерии и проверки должны быть выполнены.
- Завершённые задачи не удалять; фиксировать основание завершения.
- Физические тесты отмечать только после прямого подтверждения пользователя.
