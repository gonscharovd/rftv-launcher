## Правила ведения

- Перед добавлением задачи проверьте, нет ли её уже в этом списке и в [ROADMAP](../../ROADMAP.md).
- Используйте только статусы BACKLOG, READY, IN PROGRESS, BLOCKED, REVIEW, DONE.
- Не ставьте DONE по факту написания кода: требуемые критерии и тесты должны быть выполнены.
- Завершённые задачи не удалять; кратко фиксировать основание завершения.
