# Дорожная карта

Основание — утверждённый [ROADMAP.md](../../ROADMAP.md), актуальный на 2026-11-09. Этот файл — краткий навигационный слой, исходный roadmap остаётся детальным планом.

## Долгосрочное направление

Стабильный и быстрый Android TV launcher: стабильность → управление с пульта → визуальное качество → скорость → функции → безопасность OTA.

## Утверждённые этапы

| Этап | Статус на 2026-11-09 | Критерий |
|---|---|---|
| 1. Release pipeline и интеграция Control Center/заставки | DONE | v0.3.0 опубликован, APK и assets проверены |
| 2. Физическая приёмка и стабилизация | IN PROGRESS | Пользователь подтвердил чек-лист на Sber SDX-50U4123B |
| 3. Главный экран и визуальная система | READY после этапа 2 | Цельная дизайн-система, корректные темы/обои, производительность |
| 4. Dock и каталог | READY после этапа 2/3 | Актуальность каталога, сохранение порядка/избранного, DPAD |
| 5. TV Manager | BACKLOG | Только доказуемый, обратимый, модельно-специфичный безопасный процесс |
| 6. Производительность, совместимость, OTA hardening | BACKLOG | Проверки API/OEM/ABI, надёжный OTA и отсутствие регрессий |

## Зависимости и правила

- Этап 2 — приёмка уже опубликованного v0.3.0; не подменять её новой функциональностью.
- Дефекты, найденные на устройстве, исправлять в отдельной fix/feature ветке и включать в ближайший Release.
- Не переходить к крупному этапу, пока не завершены проверки предыдущего.
- Системные package actions не планировать как автоматическое отключение. Сначала доказать API/privilege, точную модель, зависимости, исходное состояние и rollback.
- Новые пользовательские функции и изменения концепции требуют решения Product Owner.
