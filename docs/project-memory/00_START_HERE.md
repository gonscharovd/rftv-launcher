## Быстрый профиль проекта

RFTV Launcher — нативный Kotlin Android TV launcher с эстетикой tvOS/Liquid Glass. Основная целевая платформа разработки: Sber SDX-50U4123B / Salute TV StarOS, Android 9/API 28, MediaTek MT9632, ARMv7. На проверенной базе опубликован stable Release v0.3.0 (versionCode 3). Физическая приёмка на телевизоре не подтверждена.

## Инструкция новому ИИ

1. Прочитайте этот файл и перечисленные документы.
2. Получите актуальные сведения из GitHub: default branch, HEAD, ветки, PR, последние commits, workflow runs, latest stable Release и дерево файлов.
3. Сверьте документы с кодом. Не считайте статус из старого handoff текущим без проверки.
4. Осмотрите относящиеся к задаче исходники и историю коммитов до редактирования. Не выводите устройство реализации из названия файла.
5. Сохраните пользовательские изменения. Работайте в отдельной ветке; не изменяйте `main` напрямую.
6. Не меняйте продуктовый объём без Product Owner. Безопасные внутренние улучшения и документирование допустимы.
7. После каждого логического изменения обновите только релевантные документы, а перед передачей обязательно `03_CURRENT_STATE.md`, `05_TASKS.md`, `10_SESSION_HANDOFF.md`.
8. Запустите доступные тесты и CI. Чётко отделяйте локальные проверки, CI, проверку подписанного APK и физическое тестирование.
9. Не публикуйте непроверенный APK. Signing key постоянный; не заменяйте, не экспортируйте и не раскрывайте его.
10. Подготовьте коммит и PR, если есть права. Не сливайте PR без отдельного разрешения Product Owner.
