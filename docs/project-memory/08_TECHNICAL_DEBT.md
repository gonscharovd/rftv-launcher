## Не считать установленными проблемами

- Наличие permission или package name не доказывает слежку, запись или передачу данных.
- Профили CleanYourTV для иных Sber моделей не доказывают совместимость/несовместимость каждого отдельного пакета без fingerprint устройства.
- Отсутствие Gradle wrapper в дереве — наблюдение по текущему tree, но не доказательство невозможности сборки в Android Studio/system Gradle.
- Успешный CI не доказывает работу на физическом телевизоре.

Новые дефекты добавлять только с воспроизводимым симптомом, логом/тестом/ссылкой на issue или чётко обозначать как гипотезу.
