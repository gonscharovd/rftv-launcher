## Процедура пересмотра

Не редактировать старую запись так, будто исходное решение никогда не существовало. Добавлять новую запись с датой, причиной пересмотра и ссылкой на PR/commit. Отменённые решения помечать как отменённые, сохраняя историю.

| 2026-11-09 (уточнение Product Owner) | ИИ получает полную техническую и операционную автономность; согласование требуется только для добавления новой пользовательской функциональности/разделов/сценариев или изменения концепции | Устранить искусственные остановки на внутренних инженерных шагах, не допуская самовольного расширения продукта | ИИ самостоятельно исследует, проектирует, реализует утверждённый scope, меняет архитектуру, тестирует, создаёт/сливает PR и выпускает проверенные stable Release; донорские функции не импортируются автоматически | Принято |
