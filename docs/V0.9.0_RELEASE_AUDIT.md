## 4. Реализованные исправления

### Дизайн — без переноса функциональности донора
- Home: полноэкранная фотография, центральные крупные часы и дата, погодная плашка справа сверху.
- Dock: одна тёмная стеклянная капсула, без рамок у невыбранных иконок, увеличение/подсветка сфокусированного приложения и его подпись.
- Control Center: плавающая панель справа, нижняя граница выше Dock, контрастные focused icons.
- Settings: тёмная стеклянная поверхность, боковая навигация с glyphs, отдельная область содержимого, доступный с DPAD close affordance.

### Фотографии
- Gradle извлекает существующие 20 Unsplash URL из каталога RFTV.
- При сборке проверяются HTTP, content-type, размер и JPEG signature.
- 20 реальных фотографий включаются в APK; TV runtime не зависит от доступности Unsplash.
- Home, carousel и picker восстанавливают фото в app-private cache; thumbnails создаются из локальных полноразмерных файлов.

### Погода
- Общий кэш и repository для Home, forecast и screensaver.
- Источники по порядку: Open-Meteo → MET Norway → wttr.in.
- Последний успешный прогноз сохраняется при сбое сети.
- На целевом ТВ реальная доступность этих источников ещё не подтверждена.

## 5. Что НЕ подтверждено

Владелец сообщил об установке только v0.8.0. Установка v0.9.0 на телевизор ещё не подтверждена.

Нельзя считать физически пройденными:
- визуальное качество и композицию на реальном экране;
- фактическую загрузку/отображение всех фото и offline;
- погоду и работу fallback-провайдеров из сети StarOS;
- DPAD/OK/Back, начальный/возвратный фокус;
- blur/performance на MT9632;
- DreamService и заставку;
- OTA установку и сохранность настроек.

Полный сценарный чек-лист: [DEVICE_TESTING.md](../DEVICE_TESTING.md).

**Следующий этап:** владелец устанавливает stable v0.9.0 через OTA и проверяет чек-лист. До получения результатов новые функции не добавлять.
