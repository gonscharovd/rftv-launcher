# RFTV 0.8.0 — план исправлений после приёмки v0.7.2

Дата: 2026-11-09. Установка v0.7.2 на Sber SDX-50U4123B / StarOS 1.103.91 / Android 9 подтверждена пользователем. Описанные дефекты — пользовательская приёмка, а не воспроизведённые автоматически ошибки.

## Цель и ограничения
Цель — цельная tvOS/iOS-inspired система RFTV. Приоритет: корректность изображений и данных → DPAD/фокус → визуальная система → производительность. Сохраняем Kotlin + Android Views, minSdk 24, targetSdk 28, поддержку ARMv7. Владелец подтвердил, что tvOS Launcher с полноценным live blur плавно работает на том же телевизоре; визуальный паритет по стеклу и размытию является явным требованием, а не эффектом, который нужно заранее исключить.

## Приоритеты

### P0 — обои и данные заставки
- Проверить все 20 Unsplash URL: HTTP status, redirects, content-type, размер, реальный decode bitmap, thumbnail URL и cache files.
- Добавить различимую диагностику DNS/TLS/HTTP/пустого ответа/невалидного изображения/decode error. Наличие файла не считать валидным кэшем без успешного decode.
- Сохранять последний рабочий фон; проверенный fallback на другую фотографию; градиент — последний резерв.
- Проверить цепочки fetch → parse → model → UI отдельно для Open-Meteo, XML RSS и ЦБ РФ. Проверить namespaces, кодировки, redirects, даты, выходные/праздники, timezone и mapping weather codes.
- Добавить cache последнего успешного ответа, timestamp свежести и состояния loading/available/stale/error/empty. Не показывать выдуманные данные.
- Пока оставить Челябинск как фиксированную локацию тестового устройства; геолокацию и выбор города не добавлять без отдельного согласования.

### P1 — главный экран
- Фотографические обои на весь экран, деликатное затемнение.
- Крупные часы с новой выразительной гарнитурой, стеклянная плашка интегрирована в изображение.
- Справа от часов — иконка, текущая температура, условие и город Челябинск.
- Погодная кнопка открывает glass overlay с текущими условиями и прогнозом на 5 дней; DPAD/Back/возврат фокуса обязательны.
- Удалить кнопку «Обои» с Home. Не удалять настройки дневных/ночных обоев, карусели и авто-темы.
- Не допускать мерцания, повторной загрузки на тике часов и сброса на градиент при временной сетевой ошибке.

### P2 — Dock и каталог
- Dock одностраничный; размеры плиток адаптируются к количеству избранных приложений.
- Удалить вторую строку и поведение DPAD Down/Up для раскрытия/сворачивания Dock.
- Отдельная плитка «Все приложения» в Dock открывает каталог поверх затемнённого фона.
- Сохранить избранное, порядок, скрытие, package change refresh, запуск Leanback/обычных приложений и возврат фокуса.
- Каталог — отдельная сетка/список со скроллом и управлением DPAD.

### P3 — Control Center
- Открывается справа на всю доступную высоту с учётом inset; не конфликтует с Dock.
- Стиль iOS/tvOS-inspired: стеклянная панель, группы, крупные узнаваемые иконки, подписи и читаемые focus/selected states.
- При открытии фон реально размывается и затемняется. Для Android 12+ изучить нативный RenderEffect/blur-behind; для Android 9/API 28 реализовать совместимый snapshot pipeline: снять активный wallpaper/backdrop, уменьшить bitmap до низкого разрешения, выполнить несколько быстрых box-blur проходов на worker thread и показать готовый bitmap под панелью. Кэшировать результат до смены фона; не выполнять blur на каждом кадре. Сверить поведение с tvOS Launcher.
- Оставить только реальные системные действия. При открытии фокус внутри, Back закрывает, фокус возвращается на исходный элемент.

### P4 — заставка
- Использовать тот же активный wallpaper, что и Home; не скачивать случайный отдельный фон.
- Затемнённый мягкий фон. Верхняя строка из трёх единообразных glass-карточек: часы/дата, USD/EUR к RUB из ЦБ РФ, текущая погода/город.
- Нижняя часть — две равные колонки: «Россия» слева и «Мир» справа; заголовок, источник/время, ограничение количества и скролл/ротация.
- Асинхронная загрузка, кэш, таймауты, отмена задач. Любая кнопка закрывает заставку. При отсутствии сети — последний успешный ответ с пометкой времени либо честный placeholder.

### P5 — Settings и навигация
- Цельная iOS/tvOS-inspired оболочка, категории с иконками, единые карточки и контролы.
- Удалить кнопку «Закрыть»; выход — Back.
- Left/Right переключают колонки: Right входит из левой навигации в содержимое выбранной категории; Left возвращает в левую колонку.
- Up/Down перемещают фокус внутри текущей колонки. Back возвращает на Home/предыдущий уровень.
- Selected category и DPAD focus — разные состояния; восстанавливать фокус. Исключить тупики и скрытые focusable элементы.

## Донорский аудит

### tvOS-Launcher — https://github.com/techgenius1/tvOS-Launcher
Проверены исходники `ControlPanelOverlay.java`, `Ui.java`, `SceneHome.java`, а также README; лицензия — Apache-2.0. Погодный shortcut открывает 5-day forecast modal; Control Center имеет настраиваемые плитки. Для blur донор использует snapshot и downsampled bitmap с несколькими box-blur проходами; на API 31+ доступен системный blur-behind/RenderEffect. 
Решение: перенять сценарий «погодный shortcut → прогнозный overlay», структуру независимой панели и алгоритмический подход snapshot/downsample/box blur для API 28. Не копировать UI/код вслепую; сохранить Apache notices при переносе фрагментов кода. Проверять Android 9/OEM совместимость.

### CleanYourTV — https://github.com/Gathin23/cleanyourtv
Исходники проверены: `launcher/app/src/main/java/com/gathin/tvhome/AppAdapter.java`, `AppLibraryDialog.java`, `DockSlots.java`, `GridNavigation.java`, `GlassView.java`; лицензия репозитория — MIT (`LICENSE`), шрифты и Fluent Emoji имеют отдельные лицензии.
- `AppAdapter` поддерживает отдельный single-row режим; ширина плиток уменьшается под число колонок, сохраняются identity/focus при обновлении пакетов, избранное и Leanback launch intents.
- `AppLibraryDialog` — отдельный RecyclerView-каталог с асинхронной загрузкой приложений, выбором по package name и действиями добавить/убрать приложение с Home. Сам донор явно отказывается от backdrop capture/blur: в комментариях отмечены зависания Home на 60–140 мс на одном из TCL при открытии каталога.
- `GlassView` рисует полупрозрачную заливку, блик, контур и halo, но не размывает содержимое за стеклом. Документация донора прямо фиксирует «No blur».
Решение: перенять адаптивную ширину плиток, single-row модель, отдельный каталог, устойчивую идентичность приложений и асинхронную загрузку. Не переносить запрет на blur: это осознанный компромисс CleanYourTV, тогда как владелец подтвердил работу tvOS blur на своём ТВ. RFTV использует собственный snapshot blur pipeline, проверяет его на целевом устройстве и не копирует код донора.

### Не переносить
Не копировать целиком экраны, Compose-архитектуру, зависимости, системные привилегии или непроверенные действия. Не добавлять постоянные фоновые службы и тяжёлые эффекты ради сходства. Никакие новые пользовательские разделы вне согласованного списка не добавлять.

## Критерии готовности
- Фото отображаются после cold start, смены темы и перезапуска; после первого успешного кэша доступны offline.
- Погода/валюты/RSS проходят parser tests и имеют кэш/fallback без фиктивных значений.
- Полное управление DPAD/OK/Back, без потери/тупиков фокуса.
- Dock в одну строку; DPAD Down не раскрывает; каталог открывается отдельной кнопкой.
- Control Center и overlays возвращают фокус.
- API 28/ARMv7 поддерживаются, неподдерживаемые API не используются.
- CI: unit tests, lint, Debug build, signed Release verification, SHA-256, package/version/SDK/ABI/certificate checks.
- Физическая проверка каждого сценария фиксируется только после подтверждения пользователя.


## Уточнение владельца: полноценное стекло и blur обязательны

Пользователь подтвердил 2026-11-09, что tvOS Launcher с live blur и стеклянными поверхностями работает на его Sber SDX-50U4123B. Предыдущие формулировки, заранее запрещавшие real-time blur, отменены. Нельзя снижать визуальную цель до полупрозрачных панелей только из предположения о слабом GPU.

Технический ориентир по проверенному коду tvOS Launcher: `ControlPanelOverlay.java` получает snapshot и строит blur на уменьшенном bitmap; `Ui.blur()` использует несколько горизонтальных/вертикальных box-blur проходов; на API 31+ дополнительно доступен системный blur-behind/RenderEffect. Для RFTV на API 28 реализовать snapshot + downsample + asynchronous box blur и показать его под glass overlay. Для API 31+ можно использовать нативный путь с fallback. Измерения и оптимизация остаются обязательными, но не являются поводом отказываться от эффекта.

Источник: https://github.com/techgenius1/tvOS-Launcher (Apache-2.0; переносить алгоритмический подход с сохранением авторства/лицензии, не копировать интерфейс целиком).
